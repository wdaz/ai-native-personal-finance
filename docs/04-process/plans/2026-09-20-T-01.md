**Goal:** Turn the empty repository into a runnable, lintable, typechecked, testable
Next.js workspace that matches ADR-0001/0002/0003 exactly, so every later backlog task
has somewhere to put its code and a green pipeline to keep green.

**Architecture:** One npm package at the repository root (ADR-0002 — no workspace tool).
`app/` holds the App Router, `src/{domain,shared,server,webmcp,ui}` hold the layers whose
boundaries ESLint enforces, `prisma/` and `tests/{unit,api,e2e,fixtures}` are created empty
with README stubs. Design values enter the code exactly once, as
`src/ui/tokens.css` generated from `docs/02-architecture/design-tokens.md`. Nothing in this
task implements product behaviour: the only route is a scaffold placeholder that T-05's
middleware and T-07's shell will replace.

**Tech Stack:** Next.js 16 (App Router) · React 19 · TypeScript 5.9 (strict) ·
ESLint 10 flat config (`eslint-config-next` + `typescript-eslint` + `eslint-plugin-boundaries`) ·
Prettier 3 · Vitest 5 · Playwright 1.63 (Chromium, Firefox, WebKit) · GitHub Actions.

**Spec:** `docs/03-specs/backlog.md` (T-01 row) · `docs/02-architecture/adr/0001-stack.md` ·

## Global Constraints

Copied verbatim from the approved documents. Every task below inherits them.

- **Layout is ADR-0002's tree, unchanged.** `app/`, `src/domain`, `src/shared`,
  `src/server`, `src/webmcp`, `src/ui`, `prisma/`, `tests/{unit,api,e2e,fixtures}`.
  One npm package, no workspace tool.
- **Import rules (ADR-0002):** `domain` imports nothing from `app`, `server`, `webmcp`;
  `shared` imports nothing from the rest; `app` never imports Prisma directly (only
  `server`); `webmcp` imports only `shared` and calls the HTTP API. CI must fail on
  violations.
- **TypeScript strict** (ADR-0001).
- **Design values:** `docs/02-architecture/design-tokens.md` is "the **only** source for UI
  values (`src/ui/tokens.css`); no hard-coded hex or pixel values elsewhere."
- **Typography:** Public Sans via `next/font/google`, weights 400 and 700.
- **Money is integer cents** in code and DB; formatted only at the edge. (No money code in
  T-01; the constraint is recorded so the scaffold never introduces a float helper.)
- **Clock:** nothing in `domain` or `server` calls `new Date()` for business logic
  (ADR-0005 — "lint rule").
- **Avatars:** `/avatars/<key>.jpg` where `key` is the seed's basename, e.g.
  `emma-richardson` (SPEC-overview §4.5).
- **`WEBMCP_MODE`** (`native | polyfill | off`, default `polyfill`) is the documented knob;
  `next.config` exposes it to the client as `NEXT_PUBLIC_WEBMCP_MODE`. `APP_ENV=test` is
  exposed as `NEXT_PUBLIC_APP_ENV` (SPEC-webmcp-tools §2.1).
- **E2E never targets `next dev`** — `next build && next start` (ADR-0003, build-workflow).
- **Playwright retries:** max 1 in CI, 0 locally (ADR-0003).
- **Test commands (ADR-0003):** `npm test` (unit + component), `npm run test:api`,
  `npm run test:e2e`, `npm run test:all` (what CI runs).
- **Commits:** conventional, small; English. Branch `task/T-01-scaffold`
  (`docs/04-process/build-workflow.md` §3). Agents never merge.
- **Out of scope:** everything in T-02 and later — Prisma schema, seed, reset, domain
  functions, Zod schemas, auth, shell, Overview, WebMCP adapter, Docker compose,
  API/E2E CI jobs, coverage gate, traceability script.

- [ ] **Step 2: Write `eslint.config.mjs`**

`eslint-config-next` v16 exports a flat-config array (CommonJS `module.exports`), so a
default import in ESM gives the array directly.

```js
import next from "eslint-config-next/core-web-vitals";
import boundaries from "eslint-plugin-boundaries";
import prettier from "eslint-config-prettier";

/**
 * Import boundaries are the machine-readable form of ADR-0002:
 *   domain  imports nothing from app, server, webmcp
 *   shared  imports nothing from the rest
 *   app     never imports Prisma directly (only server)
 *   webmcp  imports only shared and calls the HTTP API
 * ADR-0005 adds: no `new Date()` in domain or server business code.
 */
export default [
  ...next,
  {
    ignores: [
      ".next/**",
      "node_modules/**",
      "coverage/**",
      "playwright-report/**",
      "test-results/**",
      "docs/**",
      "next-env.d.ts",
    ],
  },
  {
    files: ["**/*.{js,mjs,ts,tsx}"],
    plugins: { boundaries },
    settings: {
      "boundaries/include": ["app/**/*", "src/**/*", "tests/**/*", "scripts/**/*"],
      "boundaries/elements": [
```
