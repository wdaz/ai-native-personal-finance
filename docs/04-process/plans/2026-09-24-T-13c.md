**F4 — TD-10: what the guard must and must not rely on.**

- **(a) `?host=` beats the URL's host in node-postgres.** Measured with the installed
  `pg-connection-string` against `new URL(...).hostname`:

  | `DATABASE_URL`                                        | host `pg` connects to | `URL.hostname`     |
  | ----------------------------------------------------- | --------------------- | ------------------ |
  | `postgresql://u:password@localhost/db?host=prod.example.com` | `prod.example.com`    | `localhost`        |
  | `postgresql://localhost@prod.example.com/db`          | `prod.example.com`    | `prod.example.com` |
  | `postgresql:///db`                                    | (none; driver default) | (empty)           |
  | `postgresql://u:password@[::1]:5432/db`                      | `[::1]`               | `[::1]`            |

  So the guard reads the host from `URL`, refuses any URL that carries `host` or `hostaddr`, and
  refuses what does not parse or names no host — it fails closed. It cannot import
  `pg-connection-string` (`src/shared` imports nothing).
- **(b) `VERCEL` alone is not a sound signal.** Vercel's "System environment variables" page (last
  updated 2026-07-15, read 2026-09-24): `VERCEL` and `VERCEL_ENV` are "Available at: Both build and
  runtime", and appear only when "Enable access to System Environment Variables" is checked in the
  project. Off, `APP_ENV=test` on Vercel carries no `VERCEL`. So the platform line is a bonus and the
  **database-host line is the one that does not depend on a setting**: Neon's host is never local.
- **(c) `next start` runs `next.config.ts` again; a serverless function does not.** Measured:
  `next start`'s log shows "Running next.config.ts took 13ms", and `APP_ENV=test
  DATABASE_URL=<other machine> next start` prints "Failed to load next.config.ts", exits 1 and
  leaves nothing listening. A Vercel function does not load `next.config.ts` (not measured — no
  Vercel here), so a build made elsewhere and deployed as-is (`vercel deploy --prebuilt`) would
  carry `NEXT_PUBLIC_APP_ENV=test`; the runtime line — `isTestEnv` refusing the same combination —
  keeps the routes at 404 there. The two lines are one function, `testEnvRefusal`.
- **(d) SPEC-reset-and-test-support §2.5 contradicts the guard.** It says "First deploy / `npm run
  db:reset` calls `resetToSeed(db, "manual")`". With TD-10, `db:reset` refuses a non-local URL.
  The same `resetToSeed(db, "manual")` is reached by `POST /api/admin/reset` with an empty body
  (§2.2, `RESET_SECRET`). Q2 asks the owner to choose and to approve §2.5/§2.7's new wording.

- **(f) Playwright reads its config for every run.** `test:api`, `test:e2e`, the UI mode and a bare

- **(g) An unset `DATABASE_URL` is not refused.** There is nothing to reset, `databaseUrl()` already

- **(h) The guard is not keyed on `NODE_ENV`** (TD-10's own warning): CI and every local API/E2E run

```ts
import { readdirSync } from "node:fs";
import { join } from "node:path";

/**
 * TD-9 (docs/03-specs/tech-debt.md): a bare `fr` track is `minmax(auto, Nfr)`, and its `auto`
 * minimum follows the widest item's min-content — one fixed-size item (Budgets' donut) then
 * forces every card in its column wider than the page at 320 px (US-33 AC2). A column track
 * is therefore written `minmax(<definite>, Nfr)`: `minmax(0, 1fr)`, or a length or percentage
 * as the minimum. `auto`, `min-content`, `max-content`, `var()`, `calc()` and `min()` as the
 * minimum do not count as definite, so they are reported too.
 *
 * Scope, deliberately as TD-9 states it: the value of `grid-template-columns`. Not read:
 * `grid-template-rows` (a row's `auto` minimum is about height, not the 320 px width),
 * `grid-auto-columns` and the `grid` / `grid-template` shorthands — nothing under `app/` or
 * `src/` uses them, and adding one is a reason to extend this list.
 */
export type BareFrTrack = { line: number; declaration: string };

const DECLARATION = /(?<![\w-])grid-template-columns\s*:([^;}]*)/gi;
const DEFINITE_TRACK =
  /minmax\(\s*(?:0|\d*\.?\d+(?:px|rem|em|ch|vw|vh|vmin|vmax|%))\s*,\s*\d*\.?\d+fr\s*\)/gi;
const FR = /\d*\.?\d+fr\b/i;

/** Every `grid-template-columns` declaration in `css` that has a `fr` track without a definite minimum. */
export function bareFrTracks(css: string): BareFrTrack[] {
  // Comments become spaces, their line breaks stay: a rule's own explanation (page.module.css
  // spells out "1fr") never counts, and line numbers stay true.
  const source = css.replace(/\/\*[\s\S]*?\*\//g, (comment) => comment.replace(/[^\n]/g, " "));
  const found: BareFrTrack[] = [];
  for (const match of source.matchAll(DECLARATION)) {
    const value = match[1] ?? "";
    if (!FR.test(value.replace(DEFINITE_TRACK, ""))) continue;
    found.push({
      line: source.slice(0, match.index).split("\n").length,
      declaration: `grid-template-columns:${value}`.replace(/\s+/g, " ").trim(),
    });
  }
  return found;
}

/** Every `.css` file under the given directories, absolute paths, sorted. */
export function cssFiles(directories: string[]): string[] {
  return directories
    .flatMap((directory) =>
      readdirSync(directory, { recursive: true, encoding: "utf8" })
        .filter((file) => file.endsWith(".css"))
        .map((file) => join(directory, file)),
    )
    .sort();
}
```

```ts
import { createHash } from "node:crypto";
import { existsSync, readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";

/**
 * TD-11: `app/fonts/` holds binary files the build serves, so what they are is checked, not
 * only written down. Every problem found in `dir` (the fonts directory) against `layoutSource`
 * (`app/layout.tsx`), one sentence each; an empty list means the directory is as its README says.
 */
export function fontProblems(dir: string, layoutSource: string): string[] {
  const problems: string[] = [];
  const readme = existsSync(join(dir, "README.md"))
    ? readFileSync(join(dir, "README.md"), "utf8")
    : "";
  // | `file.woff2` | 400 | `<sha256>` |
  const listed = new Map(
    [...readme.matchAll(/^\|\s*`([^`]+\.woff2)`\s*\|[^|]*\|\s*`([0-9a-f]{64})`\s*\|/gm)].flatMap(
      ([, file, hash]) => (file && hash ? [[file, hash] as const] : []),
    ),
  );
  const present = readdirSync(dir).filter((file) => file.endsWith(".woff2"));

  for (const file of present) {
    const expected = listed.get(file);
    if (expected === undefined) {
      problems.push(`${file} is not listed in README.md`);
      continue;
    }
    const actual = createHash("sha256")
      .update(readFileSync(join(dir, file)))
      .digest("hex");
    if (actual !== expected)
      problems.push(`${file} has sha256 ${actual}, README.md says ${expected}`);
    if (!layoutSource.includes(`./fonts/${file}`))
      problems.push(`${file} is not used by app/layout.tsx`);
  }
  for (const file of listed.keys()) {
    if (!present.includes(file))
      problems.push(`README.md lists ${file}, which is not in the directory`);
  }
  const licence = existsSync(join(dir, "OFL.txt"))
    ? readFileSync(join(dir, "OFL.txt"), "utf8")
    : "";
  if (!licence.includes("SIL OPEN FONT LICENSE Version 1.1")) {
    problems.push("OFL.txt is missing or is not the SIL Open Font License, Version 1.1");
  }
  return problems;
}
```
