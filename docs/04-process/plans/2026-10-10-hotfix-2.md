## Findings — read 2026-10-10, `origin/develop` `bb1b58e`

- **F1. H17, `<main>` is not a size container.** `src/ui/Shell.module.css` `.main` has no `container-type`. The
  Overview grid switches at `@media (min-width: 1024px)` with `grid-template-columns: minmax(0, 1fr) minmax(0, 1fr)`
  (`app/(app)/overview/page.module.css`). Neither `app-shell.md` §7's "Content width" E2E row nor `overview.md`
  §7's "Layout (v1.2)" E2E row has a test yet (`grep -rn "container-type\|1060\|608" tests/e2e` finds nothing).
- **F2. H18, the donut is Release 1's.** `src/ui/overview/donut-geometry.ts`: `DONUT_RADIUS = DONUT_SIZE / 2 -
  DONUT_STROKE / 2` (108). `Donut.tsx`: `INNER_STROKE = 8`, `INNER_RADIUS = DONUT_RADIUS - DONUT_STROKE / 2 - 4`,
  the inner stroke `color-mix(in srgb, … 25%, white)`. `Donut.module.css`: `.ring` grey-100, `.innerSegment
  { stroke-width: 8px }`. `tests/unit/ui/overview/Donut.test.tsx` finds the inner ring by `stroke-width="8"`.
  `overview.md` §7's donut E2E row (v1.3) has no test yet. H18 lists every place that changes; nothing here
  differs from it.
- **F3. H12, Overview's names.** `TransactionsCard.module.css` `.name` already cuts with an ellipsis on one line
  (no tooltip). `PotsCard.module.css` `.name` does not cut: a long pot name wraps. `TruncatedText` does not exist
  (`grep -rln TruncatedText src app tests` finds nothing). `overview.md` has no sentence about cutting names or the
  tooltip (the backlog's note, re-read: `grep -n -i truncat docs/03-specs/overview.md` finds none), so H12's
  Overview part needs that amendment first, as H12 says.
- **F4. The keyboard walkthrough.** `transactions.md` 2.9: only a cut name is a focus stop. Overview's two US-32
  E2E tests (`tests/e2e/overview.spec.ts`, 1440 px and 375 px) Tab from the banner through the four card links;
  if a seed name is cut at either width, it becomes a stop between them and both tests change. Which seed names
  are cut at 1440 px and 375 px is **not measured yet** (a *prediction*: none at 1440 px; at 375 px possibly a
  transaction name such as "Savory Bites Bistro"). Task B measures it in a browser before the amendment's words
  about the walkthrough are final.
- **F5. The design source.** The Overview names' tooltip is the designer's changelog §6d (H12). This cloud session
  cannot read the designer's Claude Design project; `transactions.md` 2.9 (v1.0.12) records the tooltip's look and
  behaviour as the designer's source stood on 2026-10-04 and 2026-10-05, and `overview.md` v1.3 records the donut as
  read live on 2026-10-06. Q2 asks whether that is enough.
- **F6. The tokens `TruncatedText` needs exist:** `--color-grey-900`, `--text-preset-5`, `--radius-100`
  (`src/ui/tokens.css` lines 19, 52, 69).
- **F7. Tests can run here:** Postgres 16 and Docker are installed in this session's container, so the API and
  E2E suites can run locally before a push (Chromium; Firefox and WebKit in CI).
