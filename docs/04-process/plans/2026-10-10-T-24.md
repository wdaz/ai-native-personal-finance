## Findings — read or run 2026-10-10

- **F1. The pre-task amendment.** The backlog note asks `budgets.md` 2.13's `delete_budget` description to say
  `busy` as `ui-kit.md` 2.3 item 2 defines it; done in its own pull request, #132 (v0.8.1), merged before this one.
- **F2. The design re-read** (H15 (5)) from `/mnt/project-files/design/` (the design source since 2026-10-10)
  matches the spec; differences are listed in the pull request and below (D5).
- **F3. The seed's centre contradicted the 128 px rule.** "$338.00" at 32 px bold is 135.4 px on Public Sans, wider
  than 128 px, so §24a's own table would show it at 20 px while §24a says "seed and ordinary amounts are
  unchanged". The designer (PROPOSE) recommended option (C), its changelog §31a: preset 1 measures against the
  whole 144 px hole when the limit is on one line, 128 px otherwise. Sent to the coordinator for the owner's role;
  the build follows (C), and `budgets.md` v0.8.2 states it.
- **F4. "of $9,999,999,999.90" fits 128 px.** At 12 px regular the widest text of that length is 127 px, so the
  maximum case needs two lines, not three; §7's E2E reads the count from the table (v0.8.2).

## Decisions

- **D1. The fit table** (`src/shared/budgets.ts`): the widest glyph of each kind ($, digit, comma, point; "of",
  "limit") in em, measured once in Chromium with the committed woff2 files; a text's width is the worst case for its
  length, so the table never under-estimates (BU-Q9 (a)).
- **D2. The bar** is an SVG `rect` whose `width` is a presentation attribute (ADR-0006 forbids `style`); the
  transition is CSS (`--duration-progress`), none under reduced motion.
- **D3. Spent and Remaining** are a `<dl>`; each figure's bar sits in its `<dt>`, pinned to the group's height,
  since a `<dl>` holds only `<div>` groups of `<dt>`/`<dd>` (axe "definition-list", found by the E2E).
- **D4. The refresh** runs in a transition (`useTransition`); the cards' area carries `aria-busy` meanwhile; cards
  are keyed by id, so an edit keeps the card and its "…" button.
- **D5. Visual differences from the design**, kept: the centre's "$338.00" at 32 px (the design export applies 128 px
  everywhere and shows 20 px — §31a); same-day Latest Spending rows ordered by timestamp, as the domain does.
