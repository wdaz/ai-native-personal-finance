Release 1 of the AI-native personal finance app: the first vertical slice, closed by T-15a (#73).

## What shipped
- Sign-in to the demo account, the app shell (sidebar, bottom nav, logout) and the periodic data reset.
- **Overview**: balance cards, pots summary, budgets donut, recent transactions and recurring bills summary.
- **WebMCP**: the two read-only Overview agent tools, through the polyfill or native WebMCP.
- Testing on Chromium, Firefox and WebKit, API tests on Postgres, axe accessibility checks, CodeQL, secret scan, npm audit and Lighthouse on production.
- Process records: discovery, PRD, ADRs, specs, backlog, process log.
