Release 2: every page of the app is built, and every page has WebMCP agent tools.

## What shipped
- **Transactions** (search, sort, category filter, pagination), **Recurring Bills**, **Budgets** and **Pots**, built from the design (T-17…T-26).
- **Writes**: Budgets and Pots can be created, edited and deleted through the shared write path, with rate limits and confirmation dialogs.
- **WebMCP**: 14 tools across all pages (`docs/03-specs/webmcp-tools.md` §4); no write tool acts without the user's confirmation (US-40). Verified with native WebMCP in Chrome 154 on production.
- Sidebar account row with logout, and the agent-tools indicator.
- Design favicon.
- Performance: Zod kept out of every page's first-load JavaScript (TD-21 hotfix); `/transactions` passes Lighthouse on production.
- Dependency advisories patched (handlebars, source-map-js, sharp).
- Phase 7: the retrospective (`docs/04-process/retrospective.md`) and the README's portfolio section; governance v1.16 ("Merge on green").
