## Fix round 1

New commit `360a28e test(ci): read test titles from the syntax tree so comments, strings and skipped groups do not count` (764acb1 not amended). Trailers are two consecutive lines, no blank line between them.

### Important 1: `titleStoryIds` on the TypeScript AST

`scripts/traceability.ts` now parses with `ts.createSourceFile(…, ScriptKind.TSX)` (`typescript` was already a devDependency; nothing added) and walks the tree:

- counts a `CallExpression` only when the callee chain is rooted at the bare identifier `test`/`it`/`describe` (or `xit`/`xtest`/`xdescribe`) and every later member is one of `describe|serial|parallel|only|skip|fixme|todo`; `/x/.test(…)`, `z.string().describe(…)` and `matcher.test(…)` are not rooted there and never count;
- the title is the first argument when it is a string literal, a no-substitution template or a template expression (literal parts, joined by a space so `US-0${n}1` cannot read as `US-01`); comments and strings are not call nodes, so they are excluded structurally;
- not counted: a chain containing `skip`/`fixme`/`todo`, an `x`-prefixed root, everything below a skipped group (the flag is inherited by every child), and a test or group whose callback holds an unconditional zero-argument `test.skip()` / `test.fixme()` at its top level. A conditional `test.skip(cond, …)` or one inside an `if` is out of scope; that is stated in a code comment and pinned by a positive-control fixture;
- exported names and signatures are unchanged (`releaseStoryIds`, `definedStoryIds`, `titleStoryIds(source)`, `checkTraceability`, `testSources`).

Known limit: `it.each([…])("title")` and titles built from a variable are not read (the callee is a call, or the argument is not a literal); every real title is a literal today.

### Failing fixtures per class (tests/unit/traceability.test.ts, 53 tests)

Every fixture is built from parts with `call()` (or a template string), so the test file's own source holds no literal test call naming a story. Each "ignores" row asserts `titleStoryIds` returns nothing and `checkTraceability(...).missing` equals `["US-02"]`:

- comment/string/method classes: line comment, block comment, JSDoc line, single-quoted string, template-literal string, a regular expression's `.test()`, a Zod `.describe()`, `.test()` on another object, expectation message, import;
- skipped-test classes: `it.skip`, `xit`, `xtest`, `test.fixme`, `test.todo`, and the own titles of `describe.skip`, `xdescribe`, `test.describe.skip`;
- skipped-group classes: a test inside `describe.skip`, `xdescribe`, `test.describe.skip`, `test.describe.fixme`, two levels below a skipped group;
- body-skip classes: a test with an unconditional `test.skip()`, one with `test.fixme()` after an `await`, a group whose body skips.

Positive controls (each must count US-02, so a scanner that counts nothing cannot pass): `test`, `it` (single quotes), `describe`, `test.describe`, `test.describe.serial`, `test.only`/`it.only`, a template title, a template title with a substitution, a test inside a group whose own title names nothing, a file with JSX, and a conditional skip (out of scope, still counts). Plus: a substitution cannot join two digits into an id, and the earlier plain cases (comment-only story reported, story outside the release not required, `US-99` typo reported).
