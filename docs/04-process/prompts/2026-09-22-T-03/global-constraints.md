## Global Constraints

Copied verbatim from the approved documents. Every task below inherits them.

- **Backlog T-03 (v1.7):** "`src/domain` for R1: `Clock`, money helpers, `budgetSpent`,
  `latestTransactions`, `recurringBills` summary, `overviewSummary`; `scripts/seed-figures.ts` that
  prints SPEC-overview §4.3 from `data.json`; unit tests assert the generated figures (values
  **and order**); repoint the boundary fixtures that import `src/domain/README.md` at the real
  domain modules". Spec / ADR: "SPEC-overview §4.3, data-model". Stories: "US-04…08 (logic)".
  Depends on: T-01. Notes: "T-03 and T-04 run in parallel with T-02".
- **SPEC-overview §4.1:** "The page performs no arithmetic; all values come from `src/domain` via
  `getOverview`."
- **§4.2:** "Formatting (`src/shared/money.ts`, `src/shared/dates.ts`)" — "All money | `$` +
  thousands separators + two decimals; negative as `-$55.50`; transaction rows prefix positives
  with `+` | `$4,836.00`, `-$55.50`, `+$75.50`"; "Dates | `d MMM yyyy`, **UTC**
  (`Intl.DateTimeFormat('en-GB', { day:'numeric', month:'short', year:'numeric', timeZone:'UTC' })`)
  | `19 Aug 2026`; `2026-08-19T20:23:11Z` → `19 Aug 2026`".
- **§4.3:** "Worked example (seed, generated by `scripts/seed-figures.ts` in T-03 — the table below
  must equal its output)".
- **§2.3:** "the first four pots in creation order"; `$920.00` is the "sum of **all** pots". **§2.5:**
  "legend: first four budgets in creation order … Totals include all budgets." **§2.6:** "Paid
  Bills", "Total Upcoming", "Due Soon". **§2.7:** empty pots → `$0.00`; no budgets → "`$0.00` /
  "of $0.00 limit""; "fewer than five transactions → available rows"; "no recurring → three rows at
  `$0.00`".
- **§6:** "`getOverview(db, clock): Promise<OverviewDto>` in `src/server/overview.ts`, composed from
  `src/domain/overviewSummary`." `OverviewDto` "(cents; dates ISO-8601 UTC)": `balance: { current,
  income, expenses }`, `pots: { total, items: [{ id, name, total, theme }] }` "first 4, creation
  order", `transactions: [{ id, name, avatar, amount, date }]` "latest 5", `budgets: { spent, limit,
  items: [{ id, category, maximum, spent, theme }] }` "first 4; totals over all", `bills: { paid,
  upcoming, dueSoon }`.
- **§7, Unit:** "`formatMoney` (positive/negative/zero/large); `formatDate` UTC incl. `20:23Z` case;
  `overviewSummary(seed, clock)` equals the generated figures of 4.3 (order included)".
- **data-model.md (v1.1):** "Money is integer cents, stored 64-bit … Dates are UTC timestamps;
  business time is fixed (ADR-0005)." `Budget` and `Pot` have "`seq` (creation order, assigned by
  the database …)". "Derived values (pure functions in `src/domain/`, all take `Clock`):
  `budgetSpent(category, transactions, clock)` = Σ |amount| of negative transactions in the current
  month. … `recurringBills(transactions, clock)` → one row per `name` among `recurring = true`, day
  = day-of-month of the most recent one, status per US-27 AC2; summary totals per US-28."
- **US-04 AC3:** "Current Balance, Income and Expenses are **stored values** … not derived from
  transactions." **US-05 AC1:** "Total Saved **$920.00** (sum of all pot totals, not only those
  displayed) and the first four pots in creation order (seed order)". **US-06 AC1:** "the five most
  recent transactions … ordered as US-11 Latest"; **AC3:** "Given fewer than five transactions, Then
  the available ones; given none, an empty message." **US-07 AC1:** "totals always include all
  budgets". **US-08 AC3:** "Given no recurring transactions, Then all three rows show $0.00."
- **US-11 AC1:** "Tie-breaks: Latest/Oldest by full timestamp then name".
- **US-27 AC2:** "Status relative to today = 19 Aug 2026 (calendar dates; time of day ignored):
  **Paid** if the vendor has a recurring transaction dated in the current month on or before today;
  **Due Soon** if not paid and its day-of-month ≤ today + 5 (≤ 24); otherwise **Upcoming**. The day
  shown … is the day-of-month of the vendor's most recent recurring transaction." **US-28 AC1:**
  "Total Bills $384.98; Paid Bills 4 ($190.00); Total Upcoming 4 ($194.98); Due Soon 2 ($59.98)".
- **ADR-0005:** "`src/domain/clock.ts` exports `Clock = { today(): Date }`; production and tests
  inject `fixedClock("2026-08-19")`. Nothing in `domain` or `server` calls `new Date()` for business
  logic (lint rule)."
- **ADR-0002:** "`domain` imports nothing from `app`, `server`, `webmcp`; `shared` imports nothing
  from the rest"; clarification 2026-09-20: `scripts/` "may import from `src/shared` and
  `src/domain` only".
- **NFR-D1:** "Business time is fixed: "today" = 2026-08-19, current month = August 2026, provided
  through an injectable clock; production and tests use the same value (OQ-4)". **NFR-D3:** "Seed =
  `data.json` with all dates shifted +2 years (2024 → 2026) at seed time".
- **DoD v1.1:** "Domain logic is pure and clock-injected; no `new Date()` in `src/domain` or
  `src/server` business code."; "Money is integer cents in code and DB; formatted only at the
  edge."; "Unit tests for every new domain/shared/webmcp function; `domain` coverage stays ≥ 90 %.";
  "Any new lint rule, config guard or document-mirror test ships with a fixture that deliberately
  violates it and a test asserting the violation is reported"; "nothing outside the task is
  changed"; "If the spec was wrong or incomplete, the spec is amended in the same PR".
- **build-workflow.md:** "Any seed-derived figure in code or tests comes from
  `scripts/seed-figures.ts`, never typed." — so every test below either reads the figure from the
  spec, derives it through `seed-figures`, or uses hand-built values chosen not to coincide with
  seed figures.
- **Governance v1.2:** "Implementer subagents … never run commands that rewrite the whole working
  tree or shared git state: `git checkout <rev> -- .`, `git reset --hard`, `git stash`, `git clean`,
  argument-less `npm install`"; "Reported output is copied from the run, never from the brief";
  "Plans mark predictions" — every **Expected** below says whether it was *measured* (in the
  scratch prototype, E8–E13) or is a *prediction*; "Rules about how tests run live in the tool's
  config".
- **AGENTS.md §2:** English; conventional commit messages; small, reviewable changes.
- **Commits.** The shared `.git/config` holds the main checkout's absolute `core.hooksPath`
  (measured 2026-09-22), so a commit here runs the main checkout's hook (scripts/README.md, "Known
  limitation"). Commit as `GITLEAKS_CACHE_DIR="$PWD/node_modules/.cache/gitleaks" git commit …`.
  Never `--no-verify`.
- **Installs touch the shared git config.** `npm ci` in this worktree runs `prepare`, which writes
  the relative `scripts/git-hooks` into the shared `.git/config`. The controller, not a subagent,
  runs it once before Task 1 and reports the change (governance v1.1/v1.2). No task adds a
  dependency.
- **Out of scope:** T-04 (Zod schemas incl. `OverviewDto`, `enums.ts`, `copy.ts`, `test-ids.ts`);
  T-09 (`getOverview`, the repository mapping, the DTO, `GET /api/overview`); T-10 (UI); the
  Release 2 functions of data-model.md (`sortTransactions`, `filterTransactions`, `paginate`,
  `sortBills`, `latestSpending`, `potPercent`); the recurring-bills page's list and counts (US-27,
  US-28 beyond the three totals the Overview shows).
