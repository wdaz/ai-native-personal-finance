## Planning

The agent read `AGENTS.md`'s reading order, the T-12 backlog row (v1.20), SPEC-webmcp-tools
(v1.0.2 as amended by v1.0.3) §2.5, §2.6, §2.8, §3 and §7, SPEC-reset-and-test-support §2.7,
ADR-0004 and ADR-0003, US-38, US-39 and US-41, NFR-W1–W3, W6, T8 and B2, the definition of done,
and the code T-11 left behind (`src/webmcp/`, `middleware.ts`, `src/server/test-support.ts`,
`next.config.ts`, the CI workflow).

As at T-11, the plan was checked against the runtime the tests will actually call, not the spec
text: the installed `@mcp-b/webmcp-polyfill@5.1.0` (`dist/index.js` and `dist/schema.js`, fetched
with `npm pack`) and the running code. That found seven things the spec text did not say
(F1–F7 in the plan), among them: a Server Component cannot pass `execute` functions to
`<WebMcpTools>`; the polyfill's `executeTool` takes a registered-tool object and a JSON string
and returns a JSON string, not `executeTool("get_balance", {})`; `getTools()` shows only two of
the annotation hints; `toErrorIssues` throws on an unrecognised Zod key; the middleware and the
route handlers are separate bundles, so the request log has to live on `globalThis`; and
`WEBMCP_MODE` is baked in at build time, so `off` needs its own build.

An advisor review of the plan, before the gate, caught three defects, fixed in plan v0.2: the
mode guards would have timed out before naming the mismatch; the deliberate-failure step needed
a by-hand `APP_ENV=test` server; and the spec amendment had missed §2.3 and §2.5.

The plan (`docs/04-process/plans/2026-09-24-T-12.md`) was the only file the planning session
wrote. It ended with three open questions for the owner and the recommendation to accept them:

- **Q1** — correct SPEC-webmcp-tools §7 (and §2.3, §2.5) to what the runtime does (v1.0.4).
- **Q2** — a tool's validation error keeps its readable `message` and adds `issues`
  (`toErrorIssues`, guarded); Release 1 inputs are `z.object({})`, not strict. Option A.
- **Q3** — the `off` CI leg runs the whole Chromium E2E suite. Option A.

The owner's reply at the plan gate, verbatim:

That is the go-ahead, taken as Q1 yes, Q2 option A and Q3 option A (the plan's recommendations),
